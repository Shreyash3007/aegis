Your AI agent is fast.
We make it trustworthy.

Agents sometimes claim work they never verified. Aegis puts the rules in code — gates, proofs, and a memory your repo keeps — so you can trust the speed without losing the truth.

The problem

The fastest developer you ever hired
is also the one that says “all tests pass” without running them.

The unverified victory lap

The agent reports success. You ship. The login flow is broken — it described the code it wrote; it never ran the app.

Monday amnesia

Friday's agent knew everything — branches, decisions, that workaround. Monday's session knows none of it.

The parallel collision

Three agents at once is the dream — until two silently overwrite each other's records and everything still looks fine.

How it works

Rules in code. Judgment in skills.
Proof on record.

A prompt is text the agent is free to ignore. Aegis splits the job: a small CLI enforces its own state and verification checks; skill procedures guide the agent's thinking. Recorded outcomes are evidence, not a sandbox or proof of adequate work.

01

Enforcement, in code

A state machine for the work itself. Illegal jumps refused. Six review gates, with human-controlled shipping. Checkpoint integrity checks recorded inputs; unrestricted shell access is outside this boundary.

02

Judgment, in skills

Phase procedures cover discovery, contract-first design, security and bug hunting. Deterministic lint checks their format; it does not prove an agent followed them.

03

A repo that remembers

brain/ is committed — the permanent second brain. Monday's agent wakes up knowing what Friday's knew. Not because the model remembered — because the repo did.

The pipeline, simplified — nine phases, six human gates (red). Full graph: 56 edges in transitions.json.

Features

Ceremony priced to the size of the change.

Fast lane

Small fixes skip the funnel — but your tests still have to pass.

aegis fix start · fix done · chore

Merge oracle

Real merge + real typecheck + contract diff before anything lands.

aegis merge check <branch>

Any stack

tsc, cargo check, go vet, py_compile — or an honest UNMEASURED, never a fake pass.

aegis typecheck

Monorepo native

Per-app pipelines, gates, and contract paths. One shared brain.

aegis init --apps web,api

Agent waves

Parallel executors recorded + checkpointed; lockfile-guarded state. 10/10 events, measured.

aegis exec -- <cmd> · aegis wave

Honest validation

Your smoke scripts become first-class gates. Every metric cites its tool — or admits UNMEASURED.

aegis validate <suite>

Loop-until-clean

Every lane re-verifies through the merge oracle. Three failed cycles escalate with an evidence pack — re-running unchanged code is doubt theater, also escalated.

aegis clean <branch>

Quarantine

Park a failing lane. The oracle refuses it until an audited clear with a reason. Human review remains the owner's responsibility.

aegis quarantine freeze · clear · list

Record memory

Typed decisions with confidence, citations, and expiry. Contradictions open reconcile tasks — never silent overwrites. Lane scratch stays sealed until promoted.

aegis memory add · reconcile · promote

Judgment ring

Batched yes/no, pick-one, and score judgments over direct TypeSafe HTTPS. No key means a degraded mode that says so — never a silent guess.

aegis jev triage · score · classify · cite

Demo approval

UI work records an HTML prototype; non-UI work records contracts and a trace. Entry to build phase 04a checks the approval. Creating a worktree is not itself approval to build.

aegis demo record · gate DEMO --approve

Trigger calibration

An optional judgment-ring evaluation checks declared cases. A historical stock-set run scored 43/43; live results vary and are not a held-out benchmark.

aegis eval trigger
Flagging

Aegis says no. In writing, with an exit code.

Aegis refuses failed CLI predicates and records the reason. These are real CLI behaviors, not aspirations:

exit 4 · illegal jump

Skipping pipeline stages is refused: ILLEGAL transition 03b -> 05a (no such edge)

exit 4 · open gate

Build-phase entry checks DEMO: gate DEMO (demo-approval) OPEN - CLI refuses

exit 9 · quarantined merge

Frozen lanes are refused until cleared: QUARANTINED … - oracle refuses until a human clears

exit 5 · doubt theater

Re-verifying unchanged code escalates: re-verified 380beb84 with no new changes

exit 2 · phantom citation

Memory cites must resolve to repo files: cite target not found … (cites must resolve)

exit 13 · nothing to merge

An empty slice is never a pass: NOTHING TO MERGE … This is NOT a pass

Aegis runs on its own repository and in disposable conformance fixtures. Earlier versions recorded live judgment calibration, synthetic pipeline walks and real field feedback. Later audits found further defects, so earlier green checks must not be described as proof that everything was closed. The v0.10 audit adds regression evidence, safer state and memory handling, exact-source verification and an installed-package check. Comparative quality, cost advantage and general small-model effectiveness remain unmeasured; the roadmap does not count scripts as model-driven trials.
